# Everfind

Everfind is an offline-first home inventory app built with Expo Router and React Native.

This repository is being prepared as the standalone open-source edition.

## Development

```bash
npm install
npm run start:foss
npm test
npm run lint
```
## Android dev client

The `Build FOSS Android dev client` GitHub Actions workflow is manual so native builds only run when needed. Open the repository's Actions tab, select the workflow, and run it; the resulting APK is attached to the workflow run for 14 days.
